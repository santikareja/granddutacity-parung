# Website Project - Grand Duta City Parung

Project ini merupakan kode sumber resmi untuk website pemasaran perumahan [Grand Duta City Parung](https://granddutacitysouthofjakarta.com), sebuah kawasan kota mandiri seluas 200 Ha yang terletak di koridor strategis selatan Jakarta. Website ini dibangun menggunakan Next.js dan Payload CMS untuk menyajikan informasi tipe unit, harga, dan promo terbaru secara real-time.
